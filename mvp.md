# MVP

## Use case: начать новую игру Судоку

**Актор:** посетитель приложения.

**Предусловия:**

- Приложение открыто в браузере.
- Пользователь находится на главной или игровой странице.

**Основной сценарий:**

1. Пользователь открывает главную страницу.
2. Пользователь выбирает уровень сложности.
3. Приложение переходит на `/game/:difficulty`.
4. Пользователь видит заглушку игрового поля.

**Результат:** пользователь попал на страницу выбранного режима.

**Альтернативный сценарий:** без указанного уровня используется `easy`; неизвестный маршрут открывает страницу 404.

## Входит в MVP

- Навигация между страницами
- Страница запуска
- Страницы правил и описания проекта
- Маршрут игры с параметром сложности
- Общая библиотека UI-компонентов
- Текстовые заглушки будущих функций

## Не входит в MVP

- Генерация поля Судоку
- Проверка введённых чисел
- Таймер и подсчёт ошибок
- Сохранение прогресса
- Авторизация и личный кабинет
- Серверная база данных
