# Архитектура проекта

## Назначение

«Судоку» — клиентское настольное веб-приложение для генерации и решения классических головоломок 9×9. Игровая логика работает в браузере, сервер и регистрация не требуются. Репозиторий разделён на два npm-проекта: приложение и переиспользуемую библиотеку общих компонентов.

## Структура репозитория

```text
apps/
  web/                         # основное приложение @sudoku/app
    index.html
    src/
      components/header.ts     # шапка и навигация
      game/sudoku.ts           # генератор, решатель и проверка правил
      pages/
        about.ts               # страница о проекте
        game.ts                # игровая страница с параметром сложности
        home.ts                # главная страница
        not-found.ts           # страница неизвестного маршрута
        rules.ts               # правила игры
      main.ts                  # точка входа и маршрутизация
      styles.css               # адаптивные стили приложения
    test/                      # тесты приложения
    tsconfig.json
    vite.config.ts
    package.json
packages/
  ui/                          # библиотека общих компонентов @sudoku/ui
    src/
      button.ts                # кнопка с вариантами и обработчиком
      card.ts                  # контейнер-карточка с заголовком и описанием
      index.ts                 # публичный API библиотеки
    test/button.test.ts        # тесты компонента Button
    tsconfig.json
    vitest.config.ts
    package.json
architecture.md
mvp.md
README.md
```

## Компоненты

### `@sudoku/ui`

- `createButton` — доступная HTML-кнопка с вариантами primary, secondary и quiet, состоянием disabled и необязательным обработчиком нажатия.
- `createCard` — секция-карточка с заголовком и необязательным описанием.

### `@sudoku/app`

- `Header` (`createHeader`) — бренд и навигация по страницам.
- `HomePage` (`renderHomePage`) — описание игры и начало новой партии.
- `GamePage` (`renderGamePage`) — выбор сложности, сетка 9×9, ввод с клавиатуры, проверка решения и сообщения о результате.
- `SudokuEngine` — генерация завершённой сетки, удаление подсказок с сохранением единственности решения и проверка допустимости ввода.
- `RulesPage` (`renderRulesPage`) — правила судоку и краткая инструкция управления.
- `AboutPage` (`renderAboutPage`) — назначение учебного приложения.
- `NotFoundPage` (`renderNotFoundPage`) — обработка неизвестного URL.

## Маршрутизация

Маршруты реализованы в точке входа `apps/web/src/main.ts`; Vite обслуживает приложение как SPA.

| URL | Страница | Параметры / доступ |
| --- | --- | --- |
| `/` | Главная | Публичная |
| `/game/:difficulty` | Игра | Параметр `difficulty`: `easy`, `medium` или `hard`; неизвестное значение заменяется лёгким уровнем |
| `/rules` | Правила | Публичная |
| `/about` | О проекте | Публичная |
| любой другой URL | Не найдена | Публичная |

Защищённых маршрутов нет: приложение не использует учётные записи и персональные данные.

## Использование библиотеки компонентов

`@sudoku/app` указывает `@sudoku/ui` как workspace-зависимость. Игровая, главная и информационные страницы импортируют `createButton` и/или `createCard` из публичного API библиотеки. Компоненты отображаются в интерфейсе, а не подменяются локальными копиями. UI-проект собирается в ES-модуль с декларациями типов перед проверкой и сборкой приложения.
