# Архитектура

## Структура репозитория

Репозиторий содержит два npm-workspace проекта: браузерное приложение и библиотеку общих компонентов.

### Основное приложение: `apps/web`

- `index.html` — HTML-точка входа приложения
- `public/` — статические ресурсы
- `src/main.ts` — запуск приложения и обработка переходов
- `src/router.ts` — сопоставление URL со страницами
- `src/components/header.ts` — навигация приложения
- `src/pages/` — главная страница, игра, правила, описание и 404
- `src/game/model.ts` — модели `Cell`, `Grid`, `Difficulty` и состояния партии
- `src/game/generator.ts` — генерация головоломки заданной сложности
- `src/game/validator.ts` — проверка корректности и полноты решения
- `src/game/game-state.ts` — создание партии и изменение пользовательских значений
- `src/game/events.ts` — делегирование событий игрового поля
- `src/game/html.ts` — экранирование пользовательского ввода перед вставкой в `innerHTML`
- `src/styles.css` — стили приложения
- `test/` — тесты приложения
- `package.json`, `tsconfig.json`, `eslint.config.js` — скрипты и конфигурация

**Назначение:** отображать страницы приложения и координировать игровой сценарий Судоку.
Модули в `src/game/` предоставляют типизированную генерацию головоломки, проверку решений и управление состоянием партии.

### Библиотека общих компонентов: `packages/ui`

- `src/button.ts` — компонент кнопки
- `src/card.ts` — компонент карточки
- `src/index.ts` — публичный API библиотеки
- `test/` — юнит-тесты UI-компонентов
- `package.json`, `tsconfig.json`, `eslint.config.js` — скрипты и конфигурация

**Назначение:** предоставлять переиспользуемые компоненты основному приложению.

## Игровая модель

- `Difficulty` — объединение сложностей `easy`, `medium`, `hard`.
- `Cell` — координаты, значение и признак исходной подсказки.
- `Grid` — квадратная сетка 9 × 9 из ячеек.
- `GameState` — сложность, исходная задача, решение, текущее заполнение и статус партии.
- `generator.ts` создаёт согласованные задачу и решение для выбранной сложности.
- `validator.ts` проверяет диапазон значений, строки, столбцы, блоки 3 × 3 и отсутствие пустых клеток в завершённом ответе.
- `game-state.ts` создаёт новую партию и не разрешает менять исходные подсказки.

## Компоненты

### `@sudoku/app`

- `Header` — навигация по страницам.
- `HomePage` — описание приложения и выбор сложности.
- `GamePage` — игровая сетка и управление партией.
- `RulesPage` — правила и краткая инструкция.
- `AboutPage` — информация о проекте.
- `NotFoundPage` — неизвестный маршрут.

### `@sudoku/ui`

- `Button` — переиспользуемая кнопка.
- `Card` — карточка контента с заголовком и описанием.

## Роутинг

| URL | Страница | Назначение |
| --- | --- | --- |
| `/` | Главная | Выбор сложности и начало партии |
| `/game` | Игра | Новая партия с лёгкой сложностью по умолчанию |
| `/game/:difficulty` | Игра | Партия с параметром сложности `easy`, `medium` или `hard` |
| `/rules` | Правила | Правила Судоку |
| `/about` | О проекте | Описание приложения |
| Любой другой URL | 404 | Страница не найдена |

Вложенные и защищённые маршруты не предусмотрены.

## Обработка событий и отображение данных

Страницы формируются через `innerHTML`, поэтому действия игрового поля обрабатываются делегированием событий на общий контейнер, а не отдельными обработчиками на каждый элемент сетки. Пользовательское значение проверяется как число в диапазоне 1–9, а текст, попадающий в HTML-атрибуты или текстовые узлы, проходит через `escapeHtml` из `src/game/html.ts`. Исходные подсказки нельзя редактировать.

## Использование библиотеки компонентов

`apps/web` подключает `@sudoku/ui` как workspace-зависимость. Компонент `Card` импортируется и отображается на главной странице; `Button` доступен через публичный API библиотеки для повторного использования.
