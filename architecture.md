# Архитектура

## Структура репозитория

Проект состоит из двух проектов в npm-workspaces.

### Основное приложение: `apps/web`

- `src/main.ts` — точка входа и подключение роутинга
- `src/router.ts` — обработка маршрутов
- `src/pages/` — страницы приложения
- `src/components/` — компоненты приложения
- `src/styles.css` — общие стили
- `test/` — тесты приложения

Назначение: собирать пользовательский интерфейс и организовывать навигацию.

### Библиотека: `packages/ui`

- `src/button.ts` — кнопка
- `src/card.ts` — карточка с заголовком и текстом
- `src/index.ts` — публичный экспорт компонентов
- `test/` — юнит-тесты компонентов

Назначение: предоставлять переиспользуемые UI-компоненты основному приложению.

## Библиотеки

- `typescript` 5.8.3 — типизированная разработка
- `vite` 6.2.6 — сборка и сервер разработки
- `vitest` 3.1.1 — тестирование
- `jsdom` 26.0.0 — DOM-среда для тестов
- `eslint` 9.24.0 — статический анализ
- `typescript-eslint` 8.29.1 — правила ESLint для TypeScript
- `tsup` 8.4.0 — сборка библиотеки UI
- `@vitest/coverage-v8` 3.1.1 — отчёт покрытия

## Компоненты

Основное приложение:

- `Header` — навигация между разделами
- `HomePage` — начальная страница
- `GamePage` — заглушка игрового поля
- `RulesPage` — описание правил
- `AboutPage` — описание проекта
- `NotFoundPage` — неизвестный маршрут

Библиотека UI:

- `Button` — кнопка-ссылка или кнопка действия
- `Card` — типовая карточка с заголовком и текстом

## Роутинг

| Маршрут | Страница | Назначение |
| --- | --- | --- |
| `/` | Home | Начальная страница |
| `/game` | Game | Заглушка игры |
| `/game/:difficulty` | Game | Игра с выбранной сложностью |
| `/rules` | Rules | Правила Судоку |
| `/about` | About | Информация о проекте |
| Любой другой путь | NotFound | Неизвестная страница |

Вложенные и защищённые маршруты в MVP не используются.

## Связь приложений

Приложение `apps/web` импортирует компоненты `@sudoku/ui` через workspace-зависимость.
На главной странице отображается общий компонент `Card`.
